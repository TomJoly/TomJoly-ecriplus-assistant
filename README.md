# 📚 Ecri+ Assistant

Extension Opera GX / Chrome qui utilise un LLM pour analyser les questions de la plateforme ecri+.

## 🚀 Installation

1. Clonez ce repository
2. Ouvrez `opera://extensions` (ou `chrome://extensions`)
3. Activez le "Mode développeur"
4. Cliquez sur "Charger l'extension non empaquetée"
5. Sélectionnez le dossier du projet

## ⚙️ Configuration

1. Obtenez une clé API (OpenAI, Mistral, ou autre)
2. Cliquez sur l'icône de l'extension
3. Entrez votre clé API et sauvegardez
